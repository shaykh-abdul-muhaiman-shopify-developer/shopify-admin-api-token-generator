# Contributing

Thank you for helping make Shopify custom app authentication easier to understand.

This repository currently contains documentation for the hosted tool. Application source is not yet published here.

## Useful contributions

- Correct a setup instruction with a link to current official documentation.
- Explain a confusing OAuth, token expiry or scope concept.
- Report a reproducible browser or installation issue.
- Add a redacted compatibility test result identifying the app type and flow.
- Improve readability and accessibility without adding keyword repetition.

## Bug reports

Include:

1. The page or step where the issue occurred.
2. Expected and actual behavior.
3. A redacted error message.
4. Browser and app/distribution type, when relevant.

Do not include Client Secrets, tokens, authorization codes, full callback URLs or private store/customer records.

## Documentation pull requests

Keep changes focused, verify links, and distinguish observed behavior from assumptions. Prefer official Shopify documentation for authentication claims.

Do not claim guaranteed permanent tokens, guaranteed search ranking, universal scope support, or complete security without evidence.

For security concerns follow [SECURITY.md](SECURITY.md), not a public exploit report.

## Support the project

If the tool saved you time, a voluntary GitHub star helps others discover it. Sharing the public repository or contributing a clear bug report is helpful too. No feature or support access is gated behind a star.
